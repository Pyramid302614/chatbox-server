For any implimenters
---------------------------
There is a function called getIP(). Because getting the connecting IP varies
depending on your setup, you need to change this to match. Typically, it is req.socket.remoteAddress,
but if you have a proxy like a cloudflared tunnel, then you might be able to use req.headers["cf-connecting-ip"],
and this is important because req.socket.remoteAddress gets the *literal request source ip*, meaning if you have a proxy,
it will always give you the ip of the proxy, which is why proxies typically (depending on who made it) include the original
request ip in the headers.

Genuinely important
---------------------------
This version actually prints every signal, meaning in newer versions, your only enemy
is *sending* invalid signals rather than revieving them. But lucky for you, I don't
plan on changing the four original signal types, so you should be fine...... for now
